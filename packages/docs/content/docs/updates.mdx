# Updates

How you update Hao Work depends on how you installed it. In every case you can check your current version at **Settings → Hao Work → About**.

## Desktop app

The desktop app checks for updates against GitHub releases. When one is available, Hao Work tells you, downloads it when you choose, and installs it on the next restart. You're always in control — nothing installs without your say-so.

## Web / CLI

If you installed the CLI, update it from **About** with the check and update buttons, or from the terminal:

```bash
openchamber update
```

Hao Work detects how it was installed (npm, pnpm, yarn, or bun) and runs the right update for you.

## The OpenCode server

Hao Work and OpenCode update separately. When a new OpenCode version is available, Hao Work offers to update it and restarts the server afterward. See [OpenCode Server](/opencode-server/) for how that server is managed.
